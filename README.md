## 🌌 Overview

**TaskFlow** is a modern task management application built with React and Vite.

The application is designed around the idea of a **"Celestial Chronicle"** — where everyday tasks become chapters in a personal journey.

It provides a complete productivity workflow for creating, organizing, scheduling, tracking, editing, and backing up tasks while maintaining a premium cinematic user interface.

---

## ✨ Features

### 📖 Task Management
- Create new tasks
- Add detailed descriptions
- Mark tasks as completed
- Edit existing tasks
- Delete tasks with confirmation
- Undo recently deleted tasks
- Pin important chapters

### 🎯 Task Organization
- Priority levels:
  - Low
  - Medium
  - High
- Categories:
  - Academy
  - Work
  - Personal
  - Projects
  - Other
- Search tasks by title or description
- Filter by task status
- Filter by category
- Sort by:
  - Newest
  - Oldest
  - Name
  - Status

### 📅 Scheduling
- Set due dates
- Set due times
- Automatic overdue detection
- Due today indicator
- Due tomorrow indicator
- Upcoming deadline indicators

### 🔔 Reminders
- Browser notification support
- Permission handling
- Task reminder scheduling
- Prevents repeated reminder notifications

### 📊 Chronicle Overview
The dashboard provides a quick overview of:

- Total chapters
- Completed chapters
- Chapters in progress
- Overdue chapters
- Overall progress
